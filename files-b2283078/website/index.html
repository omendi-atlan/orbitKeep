System Overview

Real-time operations, background processes and domain constraints

🛰

Entities

Life Support, Station Modules, Supply Pods, Astronauts — all implementing IEntity with unique IDs and status reporting.

⚡

Power & Oxygen

PowerManager reacts to critical oxygen alerts. LifeSupport drains continuously via background thread; resupply restores levels and fires events.

🧑‍🚀

Crew Operations

Create / remove astronauts, start & end EVA with domain rule enforcement (custom SpaceStationException on illegal EVA states).

📡

Background Monitor

Independent monitoring thread drains O₂ every 3 s, raises CriticalOxygenAlert and OxygenRestoredAlert events safely under lock.

Technical Requirements Implemented

Full OOP, interfaces, events, threading, exceptions & bonus logging

1. OOP Principles

  • Encapsulation — private fields + properties across entities
  • Abstraction — IEntity, IPowerConsumer
  • Inheritance — Astronaut : CrewMember : Entity
  • Polymorphism — GetStatus() overridden per concrete type

2. Interfaces

  • IEntity — Id, Name, GetStatus()
  • IPowerConsumer — power draw contract for modules
public interface IEntity {
  string Id { get; }
  string Name { get; }
  string GetStatus();
}

3. Custom Exceptions

Domain-specific SpaceStationException thrown on illegal EVA attempts.

public class SpaceStationException
  : Exception {
  public SpaceStationException(string msg)
    : base(msg) { }
}

4. Events & Delegates

  • CriticalOxygenAlert (custom delegate)
  • OxygenRestoredAlert (EventHandler)
public delegate void AlertEventHandler(
  string message, double currentLevel);

public event AlertEventHandler
  CriticalOxygenAlert;

5. Multithreading

Background Thread named StationMonitoringThread runs independently, uses Monitor lock for thread-safe oxygen drain.

6. Bonus — File Logging

Logger static class appends all major actions and alerts to log.txt with try/catch protection.

public class StationMonitor
{
    public event AlertEventHandler CriticalOxygenAlert;
    public event EventHandler OxygenRestoredAlert;

    private Thread _monitorThread;
    private readonly object _lockObject = new object();

    public void Start()
    {
        _monitorThread = new Thread(RunMonitor)
        {
            IsBackground = true,
            Name = "StationMonitoringThread"
        };
        _monitorThread.Start();
    }

    private void RunMonitor()
    {
        while (_isRunning)
        {
            lock (_lockObject)
            {
                _lifeSupport.DrainOxygen(1.5);
            }
            if (_lifeSupport.StationOxygenReserve < 20.0)
                CriticalOxygenAlert?.Invoke(
                    "[ALERT] Critical O2 Warning!",
                    _lifeSupport.StationOxygenReserve);
            Thread.Sleep(3000);
        }
    }
}
